Reconnect DevMonitor
  1. Start MySQL and confirm the devmonitor database and app user exist.
  2. Check connectivity and schema status: 
    python -m flask --app device_monitoring_prototype.app check-db
  3. From the repository root, copy device_monitoring_prototype\.env.example to device_monitoring_prototype\.env and replace the example MySQL credentials and secret key with your own. 
    Copy-Item device_monitoring_prototype\.env.example device_monitoring_prototype\.env
  4. For a new database, create tables and default roles: 
    python -m flask --app device_monitoring_prototype.app init-db
  5. For an existing database, back it up and apply the required SQL migrations listed in the README first. init-db does not alter existing tables. Restart Flask and try again.
